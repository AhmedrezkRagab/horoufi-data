# horoufi-data

بيانات ومحتوى تطبيق **حروفي** — تطبيق تعليم القراءة العربية للأطفال.

| الملف | إيه ده |
|---|---|
| `version.json` | رقم إصدار المحتوى. التطبيق بيقراه الأول عشان يعرف لو في تحديث. |
| `letters.json` | الدروس: ٢٨ حرف، ٨٤ كلمة، ومسارات الكتابة. |
| `privacy-policy.html` | سياسة الخصوصية — منشورة على GitHub Pages. |

## قاعدة مهمة عند التحديث

`version.json` و`letters.json` لازم يبقى فيهم **نفس رقم الإصدار**:

```json
version.json  →  {"v": 2}
letters.json  →  {"version": 2, ...}
```

التطبيق فيه حارس بيرفض أي تحديث لو الرقمين مختلفين. ده مقصود: `version.json`
بيتقرا من raw.githubusercontent (كاش ٥ دقايق) و`letters.json` من jsDelivr
(كاش ١٢ ساعة) — فبينهم فترة بيكونوا فيها مش متزامنين، والحارس بيمنع التطبيق
إنه ينزّل محتوى ناقص أو مخلوط.

**فالترتيب الصح للتحديث:** ارفع `letters.json` الأول، استنى، وبعدين
`version.json`.
